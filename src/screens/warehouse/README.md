# 玩家仓库界面 (Warehouse Screen) - 交互与移植说明

## 1. 界面结构与网格定义
- **容器规模**：5 行 × 9 列 = 45 格容器槽位 (`0 ~ 44`) + 下方 36 格玩家背包 (`P0 ~ P35`)。
- **单页存储容量**：第 2～4 行（槽位 `9 ~ 35`）共 **27 格/页**（与假设 A1 一致）。
- **总量计算规则**：默认采用 **所有页面物品堆叠数量之和 / 上限**（符合用户确认项 1），点击槽位 `37` 可切换查看「占用槽位数 / 已解锁槽位数」。

## 2. 槽位分配表
| 行 | 槽位索引 | 类型 | 动作标识 | 说明 |
|---|---|---|---|---|
| 第 1 行 | `0 ~ 5` | `tab` | `category:all/equipment/material/...` | 物品分类筛选，带 `selected` 选中态高亮，切换时重置页码为 1 |
| 第 1 行 | `6` | `button` | `nav_screen:inventory` | 返回角色背包 (Hub) |
| 第 1 行 | `7` | `button` | `sort_warehouse` | 按品质与名称一键整理已解锁槽位 |
| 第 1 行 | `8` | `button` | `search_warehouse` | 左键打开铁砧/模组搜索框，右键清除当前搜索词 |
| 第 2~4 行 | `9 ~ 35` | `storage` | `storage_slot` | 27 个仓库槽位；`realIdx >= unlockedCount` 显示为 `locked` 锁图标 |
| 第 5 行 | `36` | `pager` | `page_prev` | 上一页（第 1 页时为 `disabled`） |
| 第 5 行 | `37` | `pager` | `page_indicator_and_mode` | 页码显示 `x/y`，左键切换总量统计模式 |
| 第 5 行 | `38 ~ 42` | `progress_bar` | `capacity_bar` | 跨 5 格绘制总量限制条 (`当前堆叠总数 / 最大上限`)，≥75% 变橙、≥90% 变红 |
| 第 5 行 | `43` | `button` | `unlock_next` | 按序解锁下一格槽位；当 `unlockedCount >= maxSlots` 时自动隐藏 (`hidden`) |
| 第 5 行 | `44` | `pager` | `page_next` | 下一页（末页时为 `disabled`） |

## 3. 交互细节与边界处理
1. **拿放与分堆**：左键拿起/放下/合并同类堆叠（遵守 `maxStack`）；右键拿起一半或放置 1 个。
2. **快速转移**：`Shift + 左键` 在仓库与下方玩家背包之间双向快速转移；`数字键 1-9` 与快捷栏 `P27~P35` 交换。
3. **总量上限拦截**：放入物品或 Shift 存入时，若超出 `maxTotalAmount`，则自动计算剩余配额执行**部分放入**或直接拒绝，并弹出提示。
4. **筛选/搜索状态下的放入规则**：在分类或搜索视图下放入物品时，物品自动写入真实仓库数组 `slots[0..unlockedCount-1]` 的第一个空闲槽位。
