# 玩家背包与系统导航 (Inventory Hub Screen) - 交互与移植说明

## 1. 设计定位
由于 Minecraft 原版 `E` 键背包容器存在固定槽位映射限制，本界面采用 **“模组客户端自定义容器 GUI / 服务端 RPG 行囊菜单 (`/bag` 或快捷栏菜单书)”** 双兼容方案设计，同时作为通往其余 6 个系统的 **主入口 (Hub)**。

## 2. 槽位分配表 (5 行 × 9 列 = 45 格)
- **原版防具与副手列（第 0 列）**：
  - `0` 头部防具 (`helmet`)
  - `9` 胸部防具 (`chestplate`)
  - `18` 腿部防具 (`leggings`)
  - `27` 脚部防具 (`boots`)
  - `36` 副手盾牌 (`offhand`)
- **RPG 扩展首饰列（第 1 列）**：
  - `1` 项链 (`necklace`)
  - `10` 戒指 #1 (`ring1`)
  - `19` 戒指 #2 (`ring2`)
  - `28` 护符 (`talisman`)
- **角色立绘与属性预览区（中部）**：
  - `2~4, 11~13, 20~22, 29~31`：跨 3×4 格角色纸娃娃实体渲染区（模组中使用 `InventoryScreen.renderEntityInInventory`，纯容器中使用自定义贴图背景层）。
  - `5`：综合属性详情槽（悬停查看完整攻/防/血/暴/速明细）。
  - `14`：当前出战灵宠预览槽（点击直达宠物界面）。
  - `23`：当前骑乘坐骑预览槽（点击直达坐骑界面）。
  - `37~43`：底部实时属性横幅 (`dynamic_text` 层)。
  - `44`：货币钱袋详情槽（显示金币与点券）。
- **右侧快捷入口区 (Hub Navigation)**：
  - `6`：任务委托日志 (`quest`)
  - `7`：灵宠契约法阵 (`pet`)
  - `8`：皇家坐骑兽栏 (`mount`)
  - `15`：荣耀公会圣殿 (`guild`)
  - `16`：信使猫头鹰驿站 (`mail`，自动计算未读且未过期邮件数并渲染红点角标)
  - `17`：星辰私人仓库 (`warehouse`)

## 3. 交互与校验逻辑
1. **部位类型校验 (`isPlayerEquipSlotMatch`)**：将非对应部位的物品（如秘银矿石、宠物项圈或错误部位防具）放入装备槽时，系统立即拦截并弹出错误提示。
2. **Shift 快速穿戴/卸下**：在下方玩家背包 `P0~P35` 按 `Shift+左键` 点击装备可自动穿戴至对应槽位；在装备槽按 `Shift+左键` 自动卸下回背包（背包满时提示拦截）。
