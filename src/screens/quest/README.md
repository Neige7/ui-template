# 任务视图界面 (Quest Screen) - 交互与移植说明

## 1. MC 布局方案选择说明
在 Minecraft 中展示任务详情通常有两种方案：
1. **方案 A（同屏分栏 + Lore 卷宗槽 + 动态文本条）**：左侧 5×2 格 (`9~13, 18~22`) 为分页任务列表，右侧槽位 `15` 为选中任务的详情卷宗（悬停显示完整任务背景与目标进度 `x/y`），槽位 `24~26` 为真实可悬停查看属性的奖励物品预览槽，槽位 `41~43` 为操作按钮。
2. **方案 B（点击跳转二级独立详情容器）**。

本组件采用 **方案 A（同屏分栏）**，无需频繁切换容器窗口即可同屏浏览任务列表、悬停查看奖励装备词条并执行「接取 / 追踪 / 放弃 / 提交」，在模组客户端与原版容器中均具备极佳的操控体验。

## 2. 状态与按钮映射关系
| 任务状态 (`status`) | 槽位 `41` (追踪) | 槽位 `42` (放弃) | 槽位 `43` (主动作) |
|---|---|---|---|
| 未接取 (`available`) | `hidden` | `hidden` | **接取任务 (`quest_accept`)** |
| 进行中 (`in_progress`) | **追踪/取消追踪 (`quest_track`)** | **放弃任务 (`quest_abandon` · 需二次确认)** | `disabled` (显示进行中) |
| 可提交 (`claimable`) | **追踪/取消追踪 (`quest_track`)** | `hidden` | **提交领奖 (`quest_submit` · 校验背包空间)** |
| 已完成 (`completed`) | `hidden` | `hidden` | `disabled` (显示已完结) |

## 3. 分类切换与空状态
- 顶部槽位 `0 ~ 4` 对应「主线 / 支线 / 日常 / 周常 / 限时庆典」，切换分类时服务端自动将 `currentPage` 重置为 `1`。
- 当分类下任务数为 0 时，左侧中心槽位 `11` 显示空状态提示图标。
