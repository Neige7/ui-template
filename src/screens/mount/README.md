# 坐骑界面 (Mount Screen) - 交互与移植说明

## 1. 组件复用架构
本界面 **100% 复用 `src/screens/pet/CompanionTemplate.tsx` 模板组件**，在 `MountScreen.tsx` 中仅通过注入 `MOUNT_CONFIG` 配置对象完成渲染，没有任何重复的列表/分页/穿戴逻辑代码。

## 2. 与宠物界面的配置差异项
1. **移动速度展示 (`speed`)**：在坐骑详情槽（`14`）、列表 Tooltip 以及底部 `dynamic_text` 横幅中额外展示 `骑乘移动速度: +165%`，并自动汇总至角色背包属性面板。
2. **激活按钮文案**：槽位 `41` 文案与角标由「出战 / 收回」替换为 **「骑乘 / 设为默认」**。
3. **外观形态选择（槽位 `26`）**：开启 `showSpeedAndSkin: true` 后，槽位 `26` 额外渲染「坐骑外观切换」按钮，支持在已解锁形态（如「烈阳金羽形态」「星夜银辉形态」）之间循环切换。
4. **鞍具类型校验**：仅允许 `equipType` 为 `mount_saddle / mount_barding / mount_spurs` 的坐骑专属装备放入槽位 `23~25`。
