# 宠物界面 (Pet Screen) - 交互与移植说明

## 1. 核心业务规则（结合用户确认项 3）
1. **单宠出战互斥**：同时仅允许 **1 只**灵宠处于「出战」状态。当对未出战灵宠点击槽位 `41`（设为出战）时，原出战灵宠自动切换为休息状态，角色背包属性面板同步刷新。
2. **宠物专属装备槽**：默认开启 **1 个**装备槽（槽位 `23`），可通过顶部槽位 `7` 切换预览 **3 格**装备槽扩展模式（槽位 `23~25`）。
3. **护具类型校验 (`isCompanionEquipMatch`)**：仅允许 `equipType` 为 `pet_collar / pet_claw / pet_charm` 的灵宠护具放入；若尝试放入角色防具、矿石或坐骑鞍具，系统将自动拦截并提示错误。

## 2. 培养与操作按钮
- **槽位 `41`（出战 / 收回）**：切换选中灵宠的出战状态。
- **槽位 `42`（喂养升级）**：优先消耗玩家背包中的「灵宠星魂果露 ×1」（若无则消耗 500 金币），增加 `+250 EXP`；经验条 (`15~17` 跨 3 格 `ProgressBar`) 实时增长并在满额时自动升级。
- **槽位 `43`（灵宠改名）**：打开 `TextInputModal`（标注 MC 铁砧 `AnvilGUI` 输入源）。
- **槽位 `44`（放生灵宠）**：触发 `ConfirmDialog` 二次确认，确认后移除灵宠并将已穿戴的护具安全退回玩家背包。
