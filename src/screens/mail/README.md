# 邮箱界面 (Mail Screen) - 交互与移植说明

## 1. 四个子视图 (TabBar `0 ~ 3`)
1. **系统邮件（槽位 `0`）** & **玩家邮件（槽位 `1`）**：Tab 角标实时统计各自未读且未过期的邮件数 (`●N`)。
2. **CDK 兑换（槽位 `2`）**：
   - 槽位 `11` 为铁砧输入框 (`AnvilGUI`)；
   - 槽位 `19 ~ 22` 内置了四个一键测试场景按钮，分别覆盖 **兑换成功 (`success`)、无效兑换码 (`invalid`)、已使用 (`used`)、已过期 (`expired`)** 四种结果状态；
   - 兑换成功时在槽位 `24~25` 展示奖励物品并自动发放至玩家背包。
3. **发送邮件（槽位 `3`）**：
   - 槽位 `10`（收件人，`AnvilGUI`）、槽位 `11`（标题，`AnvilGUI`）、槽位 `12`（正文，`ChatListener`）、槽位 `15`（邮费显示：100 金币）；
   - 槽位 `21 ~ 24` 为 4 个暂存附件槽，可从下方背包放入未绑定物品；
   - 点击槽位 `43` 校验必填字段与邮费余额后，弹出 `ConfirmDialog` 二次确认窗口。

## 2. 边界与安全规则
- **过期邮件标灰与拦截**：当 `mail.expired === true` 时，邮件标题标灰，领取按钮设为 `disabled`，禁止提取过期附件，但允许删除清理。
- **背包满空间拦截**：单封领取或「一键领取（槽位 `41`）」时逐件检测玩家 36 格背包余量，空间不足时立即停止并提示清理背包。
